
# 🌍 Go Trip

Go Trip is an all-in-one travel management and booking platform designed to simplify journey planning for modern travelers. From securing accommodations and transport tickets to tracking real-time trip expenditures and leveraging AI to map out optimized travel plans, Go Trip serves as your digital tour guide and supervisor.

## 🛠️ Tech Stack

### Frontend
*   **Framework:** React (Vite)
*   **Styling:** Tailwind CSS & DaisyUI
*   **State & Tooling:** React Hooks, Context API / TanStack Query
*   **Authentication:** Firebase Auth

### Backend & Database
*   **Runtime Environment:** Node.js
*   **Framework:** Express.js
*   **Database:** MongoDB
*   **Security & Encryption:** JSON Web Tokens (JWT)

## ✨ Key Features

### 🔐 Authentication & Security
*   **Dual Authentication Methods:** Register seamlessly using standard Email/Password credentials or click-to-login with Google Providers.
*   **Credential Recovery:** Password recovery mechanism using automated Forget Password links.
*   **Protected Gateways:** Secure routes enforced via JSON Web Tokens (JWT) tokenization alongside robust Admin Private Authorization checks.

### 🏨 Travel & Transport Bookings
*   **Multi-Vertical Booking Engine:** Reserve hotel rooms or book transportation instantly across both Bus and Train services.
*   **Demo Payment Processing:** A simulated, production-ready checkout structure for completing bookings safely.
*   **History & Tracking:** Dedicated system logs featuring full transactional history archives and current statuses.

### 💰 Expense Tracking & AI Utilities
*   **Dynamic Expense Tracker:** Dedicated expense control page to monitor your tour investments.
*   **Automated Ledger Syncing:** Hotel booking costs automatically write and link directly onto the tracker data grid.
*   **AI Itinerary Generator:** Generate comprehensive, optimized travel schedules utilizing built-in AI intelligence.

### 👤 Profile Customization
*   **Identity Controls:** Independent workspace to modify profile images, contact records, personal metrics, and current account passwords.

## 👥 User Roles

| Role | Permissions & Access Capabilities |
| :--- | :--- |
| **Guest User** | Can view home banners, browse accommodation availabilities, and review travel metrics. |
| **Registered User** | Can execute room/vehicle bookings, process checkout states, use the AI itinerary wizard, adjust profiles, and manage personalized budget trackers. |
| **Admin** | Unrestricted access to the core administrative control center dashboard displaying user logs, analytical booking matrices, visual revenue streams, and systemic resource control filters. |
